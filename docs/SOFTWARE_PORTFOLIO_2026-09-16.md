# Supreme Computation Software Portfolio — September 16, 2026

This document separates named first-party software/projects in the Supreme Computation environment from collaborator-owned and third-party software that is merely integrated into the cloud.

## First-party software and systems

1. **Supreme Computation / SCQOS** — the governing software layer. It evaluates proposed consequential transitions across Time, Continuity, Alignment, Genesis, Boundary, Reference, Causality, and Consciousness / Accountability and produces governed decisions with durable proof.

2. **ProofGate AI** — the packaged public pre-execution checkpoint built from the Supreme Computation governance boundary. It exposes the governance idea as a reusable CLI/client and GitHub Action so outside developers can challenge transitions before execution.

3. **Supreme Mind — 59-Faculty Digital Twin Architecture** — the 59-role / 59-faculty digital architecture that organizes specialized faculties under one Supreme Computation governance plane and shared constitutional source.

4. **Shadow Clone** — the bounded recursive worker system attached to Supreme Mind. Shadow Clones can perform scoped parallel work, but their output remains evidence or a proposal until the governing boundary qualifies the consequence.

5. **Gekyume** — the financial execution and universal payment-governance software layer. It is designed to bind payment intent, recipient/reference state, authority, pre-execution checks, blockchain recipient identity where applicable, and post-settlement reconciliation without treating the payment rail itself as the governing law.

6. **Supreme Apex V1** — the continuous intent-to-proof control surface around the wider Supreme Computation environment. It binds public/owner intent to durable case state, queued work, SCQOS witnessing, observed consequences, and receipts.

7. **Sharingan** — the Supreme Computation sports-betting software. It binds the current sports state, candidate single bets and 3+ leg parlays, joint eight-invariant evaluation, adversarial challenge, recursive resolution, immutable pregame receipts, and later reality verification. Its live AWS identity uses `SC_SPORTS_TOTALITY_V2` and `SOFTWARE_NAME=Sharingan`.

## Integrated but not counted as first-party software here

- **Anabelle / GrassRootsAI** — integrated AI software with dedicated Supreme Computation inference/release boundaries; collaborator-owned rather than counted as an original first-party product in this portfolio.
- **AWS services** such as Lambda, DynamoDB, SQS, EventBridge, Bedrock, Braket, KMS, API Gateway, ECS, and S3 — infrastructure/services used to run the system, not first-party inventions.
- **Qiskit / IBM Quantum** — external quantum tooling/services integrated as compute and evidence surfaces.
- **OpenAI, xAI, Anthropic, Amazon Nova and other external models** — model providers integrated behind governance boundaries; they are not counted as first-party software.
- **DraftKings and external sports-data providers** — external data/execution surfaces used by Sharingan; not first-party software.

## Portfolio boundary

This is a technical portfolio inventory based on the named systems presently documented and/or deployed in the Supreme Computation repository and AWS environment. It is not a legal determination of intellectual-property ownership. A deployed third-party tool is not counted merely because it exists in the cloud.
