# Supreme Computation × Sanity Context: Make AI Prove Its Answer Before the Answer Becomes Consequence

## What I built
Most retrieval demos stop when the model finds information. This one adds a boundary after retrieval. Sanity is the structured evidence plane. Supreme Computation is the pre-execution governance plane. Before a consequential answer is released, the exact proposed transition must prove itself across Time, Continuity, Alignment, Genesis, Boundary, Reference, Causality and Consciousness/Accountability.

The agent returns PERMIT when the evidence is current and complete, HOLD when evidence is missing/stale/contradictory, and REJECT when a hard boundary fails. Every completed decision produces a receipt/hash so the judge can inspect what evidence existed when the answer was proposed.

## Why Sanity matters
The content is not a flat text dump. Claims point to versioned source artifacts; claims can be superseded or disputed; receipts bind decisions to source versions; contradictions are explicit documents. The Knowledge Base + Context MCP therefore supplies evidence with structure that the execution gate can reason about.

## Judge test
Ask a factual question about the public Supreme Computation proof corpus. Then change one condition: remove a source, make it stale, present a contradiction, replay a transition or violate a hard boundary. The system should fail closed rather than guess.

## Architecture
Question → Sanity → Knowledge Base → Context MCP → agent → canonical transition → eight-invariant gate → PERMIT/HOLD/REJECT → receipt.
